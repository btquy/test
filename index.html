Nội dung 5 buổi học

Từ con số 0 đến website hoạt động – theo lộ trình thực chiến từng bước.

1

Tổng quan về Vibe Coding

Xu hướng lập trình mới · Quy trình 5 bước · Làm chủ VS Code · Xây landing page đầu tiên bằng AI

2

Nền tảng website cho người không chuyên

Frontend · Backend · Database · API · Nguyên tắc UI/UX cơ bản · Bảo mật API key

3

Định hình ý tưởng ứng dụng cùng AI

Viết PRD chuyên nghiệp · Xây dựng từng module · Điều hướng màn hình · Tinh chỉnh giao diện

4

Debug, kiểm thử và hoàn thiện UX

Nhận diện lỗi thường gặp · Đọc lỗi · Mô tả cho AI phân tích · Kiểm thử bằng dữ liệu mẫu

5

Deploy, demo và mở rộng AI Coding Tools

Chuẩn bị kịch bản demo · Publish lên Internet · Giới thiệu các AI coding tool nâng cao
